# 💊 MediComp

Ghid mobil offline pentru medicamentele autorizate in Romania.

Acest repository contine **doar aplicatia distribuita** (fisiere APK) — nu contine codul sursa.

### 📥 [Descarca ultima versiune (APK)](https://github.com/MediCompRo/MediComp-App/releases/latest/download/MediComp-latest.apk)

Link-ul de mai sus duce mereu la cea mai recenta versiune publicata.

## Functionalitati

- **Cautare rapida** dupa denumire comerciala sau substanta activa, in peste 21.000 de medicamente autorizate.
- **Informatii complete despre fiecare medicament**: indicatii terapeutice, contraindicatii, avertismente si precautii, doze si mod de administrare, proprietati farmacodinamice/farmacocinetice si prospectul oficial (cu link direct catre sursa).
- **Avertismente rapide**: conducere auto, sarcina, alaptare, functie hepatica/renala, substante stupefiante.
- **Compatibilitati farmacologice** intre medicamente, cu nivel de severitate (contraindicat / major / moderat / minor).
- **Compatibilitati IV** pentru medicamente administrate intravenos.
- **Lista de medicamente salvate**, pentru acces rapid ulterior.
- **Distribuire** a informatiilor direct din aplicatie (ex. catre un medic sau farmacist).
- **100% offline** dupa prima configurare — se descarca o singura data baza de date locala; ulterior aplicatia functioneaza fara conexiune la internet.
- **Actualizare automata**: aplicatia poate verifica si instala noi versiuni direct din acest repository.

## Instalare

1. Descarca [ultima versiune (APK)](https://github.com/MediCompRo/MediComp-App/releases/latest/download/MediComp-latest.apk).
2. Pe telefon, permite instalarea aplicatiilor din surse necunoscute pentru fisierul descarcat (Android va cere aceasta confirmare automat).
3. Deschide aplicatia — la prima lansare se va descarca baza de date cu medicamente (recomandam Wi-Fi).

## Informatie importanta

Aplicatia ofera informatii orientative, provenite din surse oficiale (EMA, ANMDM, RCP-uri autorizate), dar acestea pot fi incomplete sau depasite. Aplicatia **nu inlocuieste consultul medicului sau farmacistului**, iar decizia terapeutica finala apartine exclusiv personalului medical autorizat.
